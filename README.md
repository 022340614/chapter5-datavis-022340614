# 第五章 - 子图数据可视化平台

基于第五章内容构建的公共数据可视化平台，展示子图布局、坐标轴共享等高级可视化技术。

## 功能特性

- **多子图布局**: 展示固定区域和自定义区域的子图布局
- **坐标轴共享**: 实现相邻和非相邻子图的坐标轴共享
- **交互式导航**: 支持多个可视化案例的切换浏览
- **响应式设计**: 适配不同屏幕尺寸的设备

## 包含案例

1. **产品销售额分析** - 产品A与产品B的销售额对比分析
2. **养猫养狗人群比例** - 12个国家宠物人群比例对比
3. **抖音用户分析** - 2017-2018年用户分布变化分析
4. **气温与水量关系** - 双Y轴图表展示气候数据关系
5. **汽车销售情况** - 多子图布局展示销售数据

## 技术栈

- Plotly.js - 交互式图表库
- HTML5/CSS3 - 现代Web技术
- JavaScript - 交互逻辑实现
